# IDEATE 🤓

1. หุ่นยนต์ถังขยะ ที่รูปร่างหน้าตาเป็นมิตร มีเซนเซอร์รอบตัว มี Lidar ใช้ตรวจจับสิ่งของรอบตัว สามารถเคลื่อนที่ไปมาได้เล็กน้อย มีฟังก์ชันพูดเรียกหรือเตือนให้นักเรียนมาทิ้งขยะให้ถูกที่ เช่น ทิ้งที่ตัวหุ่นยนต์ของตัวเอง อาจคุยเล่นได้เล็กน้อย

2. แอป “Food Waste Tracker”
 ให้นักเรียนสแกน QR หลังทานอาหาร → เลือกว่ากินเหลือมากน้อยแค่ไหน → ระบบเก็บข้อมูลว่า เมนูไหนถูกทิ้งเยอะที่สุด → โรงอาหารใช้ข้อมูลปรับปริมาณการทำอาหาร เพื่อลดขยะอาหารโดยตรง

 3. เกม/ระบบสะสมแต้มแยกขยะ เป็นระบบที่ให้นักเรียน แยกขยะให้ถูกประเภท -> สแกน/กดบันทึก -> ได้คะแนน -> สะสมแต้ม -> แลกรางวัล (รางวัล ไม่จำเป็นต้องเป็นของราคาแพง เช่น สิทธิ์เลือกเพลงตอนพัก, badge ในระบบ, คะแนนสะสมสำหรับกิจกรรม หรือของรางวัลเล็ก ๆ จากโรงเรียน)

 4. Web App ที่ให้นักเรียนและบุคลากร แจ้งปัญหาขยะ เศษอาหาร น้ำเสีย และกลิ่นเหม็น ภายในโรงเรียน พร้อมรวบรวมข้อมูลเพื่อให้ผู้รับผิดชอบสามารถติดตามและแก้ไขปัญหาได้อย่างรวดเร็ว
