# Identified Insights
1.การทิ้งเศษอาหารลงในท่อเกิดจากความสะดวกและการจัดการจุดทิ้งขยะที่ยังไม่เพียงพอ

-> นักเรียนบางส่วนเลือกทิ้งเศษอาหารลงท่อ เพราะจุดทิ้งขยะหรือจุดแยกเศษอาหารเข้าถึงได้ไม่สะดวก ทำให้เกิดการทิ้งขยะไม่เป็นที่และเศษอาหารไหลลงสู่ระบบระบายน้ำ

2.ปัญหาน้ำเสียและกลิ่นเหม็นไม่ได้เกิดจากการทิ้งขยะเพียงอย่างเดียว แต่เกิดจากการสะสมของเศษอาหารในระบบระบายน้ำ

-> เศษอาหารจากการประกอบอาหารและการรับประทานอาหารถูกทิ้งลงในท่อ เมื่อสะสมเป็นเวลานานจึงทำให้เกิดน้ำเสียและกลิ่นเหม็นบริเวณหน้าโรงเรียน

3.นักเรียนรับรู้ถึงปัญหา แต่ยังต้องการวิธีจัดการที่ง่ายและทำได้จริงในชีวิตประจำวัน

-> จากข้อมูลพบว่าผู้ใช้ต้องการจุดทิ้งขยะและจุดแยกเศษอาหารที่มีจำนวนเพียงพอ ครอบคลุม และเข้าถึงง่าย เพราะความยุ่งยากในการหาที่ทิ้งอาจทำให้เลือกทิ้งรวมกันหรือทิ้งลงท่อ

4.ปัญหานี้ส่งผลต่อความรู้สึกและสภาพแวดล้อมของนักเรียนโดยตรง

-> นักเรียนรู้สึกรำคาญและไม่สบายใจเมื่อต้องพบกลิ่นเหม็นเป็นประจำ และมองว่าปัญหานี้ส่งผลต่อสภาพแวดล้อมภายในโรงเรียน

5.ผู้ใช้ไม่ได้ต้องการเพียงการแก้ปัญหาเฉพาะหน้า แต่ต้องการระบบจัดการขยะที่มีประสิทธิภาพมากขึ้น

-> จากการสัมภาษณ์พบว่าการแก้ปัญหาที่มีอยู่ยังเป็นเพียงการแก้ไขเบื้องต้น จึงเกิดความต้องการหาแนวทางหรือเทคโนโลยีใหม่ ๆ เพื่อช่วยจัดการขยะและเศษอาหารอย่างเป็นระบบ
